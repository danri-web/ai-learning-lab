# 演示脚本（AI Learning Lab）

给「交给老师看」用。分三种场合，挑一种就行；前两种不用装任何东西。

---

## A. 老师只点 GitHub 链接（最常见）

发这一个地址就够：

<https://github.com/danri-web/ai-learning-lab>

老师会看到：仓库简介 + topics → README 第一屏的状态/能力清单 → 12 张界面截图 → 「快速开始」四条命令 → 审计与测试记录（想检查"真的能跑"的人会翻到）。

**要提前确认的三件事**

1. README 里写的是 `npm run seed:demo`（示例数据），这条命令存在且能用 —— 见 `demo/README.md`
2. 截图是当前界面的样子（2026-11-01 重拍过 5 张）
3. 仓库是 public（老师不用登录也能打开）

---

## B. 老师自己跑一遍（4 条命令）

```powershell
git clone https://github.com/danri-web/ai-learning-lab.git
cd ai-learning-lab
npm install
npm run seed:demo    # 铺 3 篇笔记 + 2 条资源 + 2 个任务
npm run dev          # → http://127.0.0.1:3000
```

环境：Windows 10/11 + Node.js 24（`.nvmrc` 没有，`package.json` 没写 engines，README 里标了实测版本）。第一次 `npm install` 约 1–2 分钟。

> 不跑 `seed:demo` 也能用，只是打开是空的 —— `content/` 按 D5 不进仓库。

---

## C. 现场 / 录屏演示（3 分钟）

屏幕：1920×1080 起步，浏览器缩放 100%，窗口最大化。演示前把 `content/` 清干净再 `npm run seed:demo`，保证数字和截图一致。

| 时间 | 做什么 | 一句话说清 |
| --- | --- | --- |
| 0:00–0:15 | 打开 `/`（总览） | 「所有数字都是从文件现算的，没有数据库、没有缓存」 |
| 0:15–0:40 | 点「学习任务」→ 改一条状态 | 「三档状态、截止日期会算逾期」 |
| 0:40–1:10 | `/knowledge` → 打开一篇中文标题笔记 | 「文件名就是标题，支持公式、表格、代码高亮；正文 HTML 不执行」 |
| 1:10–1:35 | `Ctrl+K` 输入 `transformer` | 「搜笔记 + 搜资源，摘要高亮，不建索引所以永远不过期」 |
| 1:35–1:55 | `/resources` → 按标签筛选 | 「链接只收 http/https，应用从不抓取你填的地址（防 SSRF）」 |
| 1:55–2:20 | `/backup` → 立即备份 → 预览恢复 | 「zip 带每个文件的 sha256；恢复先快照、失败回滚；写一半被强杀下次启动自动回」 |
| 2:20–2:40 | 改一篇笔记 → 恢复刚才的备份 | 「数据真的回来了」 |
| 2:40–3:00 | `/settings` | 「默认只听 127.0.0.1；局域网要显式开、要口令」 |

**想加手机那一段**（大约 +40 秒，需要提前准备）：

```powershell
npm run auth:set-password       # 设一次口令，写进 .env.local
npm run build
npm run start:lan               # 终端会打印 http://<局域网 IP>:3000
```

手机连同一个 Wi-Fi，打开那个地址，输口令登录 —— 五个页面都能看，写入同样要过认证。注意：局域网是 HTTP、不加密，只在可信网络下演示。

## 录屏怎么出片

- 工具：Win 自带的 **Win+G**（Xbox Game Bar）或 OBS；录浏览器窗口即可
- 长度：2–3 分钟，不要剪得太碎；一段只讲一件事
- 上传：GitHub → Releases → Draft a new release → 附 `.mp4`（不要提交进仓库；大于 100 MB 会被拒）
- README 里加一行指向 Release

---

## 常见翻车点

| 现象 | 原因 / 处理 |
| --- | --- |
| `npm run dev` 报端口占用 | 换端口：`npx next dev -H 127.0.0.1 -p 3001` |
| 打开是空的 | 没跑 `npm run seed:demo`；或 `content/` 被清过 |
| 手机连不上 | 防火墙「专用网络」没放行 3000；确认用的是 `start:lan` 不是 `dev` |
| 演示时看到测试数据（"危险链接测试"之类） | 那是历史遗留条目，删掉再录 |
