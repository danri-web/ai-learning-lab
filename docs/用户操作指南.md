# AI Learning Lab · 用户操作指南

> 给使用这个工作台的人。只讲怎么用，不讲安装。
> 电脑上打开 <http://127.0.0.1:3000>；手机地址和口令找管理员要。

## 0. 一分钟上手

1. 打开「知识库」→「新建笔记」→ 写标题和正文 →「创建」。
2. 按 `Ctrl+K`，输入关键词，回车打开结果。
3. 「资源收藏」→「收藏资源」，把论文/教程/GitHub 链接存进来。
4. 「学习任务」→「新建任务」，给它一个截止日期，关联刚写的笔记。
5. 回「总览」看数字；重要内容去「备份」点一次「立即备份」。

## 1. 五个页面

| 页面 | 用来做什么 |
| --- | --- |
| 总览 | 笔记/资源/任务的数量，最近更新，进行中的任务 |
| 知识库 | 写、读、改、删 Markdown 笔记；文章详情右侧有目录 |
| 资源收藏 | 存论文、教程、文档、仓库、视频、工具；筛选和排序 |
| 学习任务 | 待办 / 进行中 / 已完成，截止日期，关联笔记与资源 |
| 备份 | 建备份、校验、预览恢复；恢复是管理员动作 |

左上角品牌名回总览；窄屏（手机）用顶部按钮打开抽屉导航。

## 2. 写一篇笔记

1. 「知识库」→ 右上角「新建笔记」。
2. 填**标题**、**分类**、**标签**（逗号分隔，可留空）。
3. 在左边写 Markdown，右边实时预览；窄屏点「预览」切换。
4. 点「创建」。标题会生成文件名（中文照抄），**创建后不再改名**；重名自动加 `-2`。

正文支持：

- GFM：表格、任务列表、删除线、围栏代码块
- 代码高亮；行内公式 `$...$`、块级公式 `$$...$$`
- 标题会自动生成右侧目录
- 内部链接：`[另一篇](/knowledge/另一篇的id)`；外部链接自动新标签页打开

编辑已有笔记：打开它 →「编辑」→ 改 →「保存」。有未保存改动时关页面，浏览器会拦一下。

删除：打开笔记 →「删除」→「确认删除」。文件会移到 `content/articles/.trash/`，**不是真删**；要找回就找管理员把它拖回来。

小规则：

- 标题别用 `con` / `nul` / `new` 这类 Windows 保留名（界面会自动加前缀）。
- 日期由应用维护，不用手填。
- 笔记 frontmatter 写坏只会单独报错，不会让整个知识库打不开。

## 3. 搜索

- 任何页面按 `Ctrl+K`（Mac 是 `⌘K`）打开搜索；再按一次或 `Esc` 关闭。
- 输入关键词，结果分「笔记 / 资源」两组，命中的字会高亮。
- `↑` `↓` 选，`Enter` 打开，`Esc` 关闭。
- 搜索的是**文件当前内容**，没有索引，所以刚改完立刻就能搜到。
- 中文输入法组字时按回车是选词，不会误打开结果。

## 4. 收藏资源

1. 「资源收藏」→「收藏资源」。
2. 填**标题**、**链接**（只接受 `http://` 或 `https://`）、**类型**、分类、标签、描述。
3. 可以选一条「关联笔记」，方便从资源跳回上下文。
4. 点「收藏」。

- 类型：论文 / 教程 / 文档 / GitHub 仓库 / 视频 / 工具 / 其它。
- 应用**不会去抓取**你填的链接，只保存地址；`javascript:`、`data:`、`file:`、裸域名都会被拒绝。
- 列表上方可按类型、分类、标签筛选；排序有「最近更新 / 最近添加 / 按标题」。
- 编辑/删除在每条资源的操作区；删除同样会留档。

## 5. 学习任务

1. 「学习任务」→「新建任务」。
2. 填标题，选状态（待办 / 进行中 / 已完成），可填截止日期和备注。
3. 勾选关联的笔记与资源（都可多选）。
4. 点「创建任务」。

- 列表里可以直接改状态；逾期未完成的会标红。
- 顶部显示待办 / 进行中 / 已完成 / 逾期数量；「总览」用的是同一份真实数据。
- 目前没有完成时间、没有提醒通知 —— 到期要自己看。

## 6. 备份（用户也能点）

- `/backup` → 右上角「立即备份」；看到“备份已创建并通过自检”就是成功。
- 列表里可以「校验」「下载」；恢复会改动全部数据，交给管理员做。
- 备份是**明文 zip**，会包含你的笔记。**不要把密码、密钥、身份证号之类写进笔记**。

## 7. 手机访问

1. 找管理员确认已经开启局域网模式，并拿到 `http://192.168.x.x:3000` 和口令。
2. 手机和电脑连同一个 Wi-Fi。
3. 打开地址 → 输入口令 → 进入；12 小时内不用再登录。
4. 退出登录在「设置」页底部。

手机只在**可信 Wi-Fi** 下用；局域网是 HTTP，不加密。

## 8. 注意（会疼的几条）

- 数据在这台电脑上，不在云里；换电脑/重装前先让管理员备份。
- 同一篇笔记别在两个标签页同时改：后保存的会被提示“内容已变”，可以选「仍然覆盖」，但先看清再点。
- 删除先进回收站；回收站清掉就真没了，只能靠整库备份回滚。
- 不要在应用运行时手改 `content/resources.json` / `content/tasks.json`，容易和界面写入打架。
- 界面报“读不出来”时不要反复保存：应用在保护坏文件，按提示修好或找管理员。
